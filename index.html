Aviso de Privacidad y Responsabilidad

Las guías generadas son de acceso público vía URL. No incluyas datos personales sensibles (DNI, pasaporte, tarjetas de pago o localizadores PNR completos). ChesTrips no se responsabiliza de la custodia o divulgación de datos introducidos por terceros.

¿Cómo funciona la arquitectura por dentro?

ChesTrips utiliza un flujo serverless en el Edge de Cloudflare:

Gemini Flash (Compilador) ➔ GitHub REST API (Storage) ➔ Edge Delivery ➔ PWA Cliente

Cada guía es un archivo monolítico 100% autónomo con HTML, CSS, JavaScript y persistencia de notas en el almacenamiento local del dispositivo.
