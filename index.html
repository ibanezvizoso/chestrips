Publica tu Web/App de Viaje

Convierte tus notas de viaje en una web/app interactiva y lista para usar en el móvil en 3 sencillos pasos.

1

Genera el archivo con ChesTrips Gem

Abre nuestro Gem de Gemini, pega tu itinerario, hoteles, enlaces o reservas y pídele que compile tu web/app de viaje en un único archivo HTML autocontenido.

Abrir ChesTrips Gem
2

Sube el código a GitHub

No necesitas usar la consola ni instalar programas. Puedes hacerlo directamente desde el navegador:

  1. Entra al repositorio y haz clic en "Add file" → "Create new file" (o "Upload files").
  2. Pega el código HTML completo que te entregó el Gem.
  3. Escribe el nombre del archivo en la casilla superior (usa nombres únicos).
  4. Abajo, haz clic en "Commit changes" (o "Propose changes" si es un Pull Request).
Evita nombres genéricos: Si lo llamas grecia.html podrías sobreescribir el viaje de otra persona. Usa nombres específicos con vuestros nombres o fechas, por ejemplo: grecia-antonio-y-laura.html o japon-octubre-paco.html.
Ir al Repositorio en GitHub
3

¡Tu web/app lista para el móvil!

Una vez aceptado el archivo en el repositorio, tu guía se publicará en internet en cuestión de segundos en:

tudominio.com/tu-archivo.html

Ábrela desde Safari o Chrome en tu teléfono y pulsa "Compartir" → "Añadir a pantalla de inicio". Funcionará como una app independiente durante tu viaje, incluso sin cobertura para lo que guardes en memoria.

Aviso de Privacidad y Seguridad

No incluyas datos confidenciales: Evita introducir números de pasaporte o DNI, códigos localizadores completos de vuelos (PNR), direcciones personales o datos de pago.

Descargo de responsabilidad: Al tratarse de un repositorio y un despliegue de acceso público, el usuario es el único responsable de la información que decide incluir en el archivo. ChesTrips no se hace responsable de la custodia, difusión o uso indebido de los datos personales publicados por terceros.

¿Cómo funciona la arquitectura por dentro?

ChesTrips utiliza un enfoque GitOps estático serverless sin base de datos central:

Gemini Gem (Frontend Compiler) ➔ GitHub (Storage & Version Control) ➔ CI/CD Edge Deployment ➔ PWA Cliente

Cada archivo HTML es autónomo: integra sus propios estilos, lógicas interactivas y almacenamiento local en el dispositivo (localStorage). El alojamiento estático distribuye el contenido desde nodos de red cercanos a tu destino para una carga instantánea.
